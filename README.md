# 🏨 MERN Stack Tourism & Hotel Management System

A **full-stack web application** for managing tourism bookings and hotel reservations, built using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)**.

## 🛠 Tech Stack  
- **Frontend:** React.js, Tailwind CSS  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB (MongoDB Atlas)
